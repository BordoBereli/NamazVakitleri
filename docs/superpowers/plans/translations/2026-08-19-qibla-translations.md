# prayer_feature/qibla Translations Appendix

Target directory: `prayer_feature/qibla/src/main/res/`

Create one file per language. Each file contains the 12 qibla strings: `qibla_calibrate, qibla_calibration_required, qibla_accuracy_medium_badge, qibla_accuracy_high_badge, qibla_waiting_location, qibla_location_error, qibla_degrees_north, qibla_turn_right_pill, qibla_turn_left_pill, qibla_aligned_pill, qibla_compass_arrow, qibla_kaaba`. Preserve the `%1$d` placeholder exactly.
