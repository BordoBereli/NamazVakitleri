# prayer_navigation/core Translations Appendix

Target directory: `prayer_navigation/core/src/main/res/`

Create one file per language. Each file contains the 4 navigation strings: `navigation_home, navigation_prayer_times, navigation_qibla, navigation_settings`.

## values-ar/strings.xml

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <string name="navigation_home">الرئيسية</string>
    <string name="navigation_prayer_times">الصلوات</string>
    <string name="navigation_qibla">القبلة</string>
    <string name="navigation_settings">الإعدادات</string>
</resources>
```
