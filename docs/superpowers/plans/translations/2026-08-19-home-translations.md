# prayer_feature/home Translations Appendix

Target directory: `prayer_feature/home/src/main/res/`

Create one file per language. Surah names are NOT included (they fall back to the transliterated `values/`). Each file contains the 12 non-surah home strings: `app_name, home_page_fallback, prayer_times_title, view_all_prayers, time_until_message, time_until_prayer_format, time_until_sunrise, unknown_error_message, share_verse, no_verse_available, shared_from_app, retry`. Preserve the `%1$s` placeholders exactly.

```xml
<?xml version="1.0" encoding="utf-8"?>

    <string name="app_name">NamazVakitleri</string>
    <string name="home_page_fallback">المسجد النبوي</string>
    <string name="prayer_times_title">صلوات اليوم</string>
    <string name="view_all_prayers">عرض الكل >></string>

    <string name="time_until_sunrise">الوقت المتبقي حتى الشروق</string>
```
