# prayer_feature/prayertimes Translations Appendix

Target directory: `prayer_feature/prayertimes/src/main/res/`

Create one file per language. Each file contains the 5 prayertimes strings: `page_title, page_sub_title, image_desc, today, previous_month, next_month`.

## values-ar/strings.xml

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <string name="page_title">أوقات الصلاة</string>
    <string name="page_sub_title">المواعيد الشهرية للصلاة</string>
    <string name="image_desc">قبة</string>
    <string name="today">اليوم</string>
    <string name="previous_month">الشهر السابق</string>
    <string name="next_month">الشهر التالي</string>
</resources>
```
